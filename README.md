# 生活小助手 · Lifeisgood

面向个体经营者、中小企业主及个人日常使用的中文工具门户。首页分为开店与工作、生活小工具、创意与娱乐；经营旅程、公共能力和行业扩展保留在工作路径中。

仓库：https://github.com/liuliu2024/lifeisgood

## 当前基础版本

- 中文任务首页、经营阶段、公共工具与行业入口；从历史89项中筛出87项具有网页交付路径的候选，可搜索、查看详情和收藏，执行状态仍为待接入。桌面本机截图及尚未核实的口播粗剪不在前台展示。
- 生活16项、创意16项入口复用原FUN编号（共27个唯一能力），跨合集收藏不重复；历史12条新建议按网页范围保留11条，撤下本机批量改名。新建议支持搜索/详情，尚无处理或上传功能，不计入原89项研究快照。
- 详情列出网页输入、浏览器或平台后台处理、结果交付方式；桌面专用候选不作为网页方案展示。保留网页封装路径不等于已接入或验证跑通，用户不需自行安装桌面软件。
- 本地邮箱密码账号、普通用户与站长权限；注册不自动提权，邮箱尚未验证。
- 修改密码需验证当前密码，成功后撤销全部旧会话并轮换当前登录。
- 私有工作空间、文件上传/下载/删除、账号收藏持久化、任务空态。
- 站长可保存站点名称、联系邮箱和公告草稿，并明确应用到网站；保存草稿不改变访客页面，公开内容以纯文本显示。具体软件、模型与API由站长以后选择，真实工具调用和支付保持关闭。
- 多窗口编辑配置时校验草稿版本；冲突保留当前输入，需明确重新读取后才能继续保存或应用，避免覆盖或应用未看过的草稿。
- 电脑、平板、手机适配，支持键盘与减少动效设置。

技术栈：Next.js/React/TypeScript、FastAPI、SQLite。此版本是本机开发底座；邮件验证、账号找回与注销、团队成员权限、生产部署和付费通道尚未完成。先前图片/文档技术试验的API保留在代码中，未作为已接入工具展示。

Python 3.12、Node.js 22以上。安装、启动、站长初始化及验证见 [本机运行说明](docs/operations/LOCAL_DEVELOPMENT.md)。运行数据、账号凭据与测试截图均留在忽略目录，不提交Git。两个开发服务仅监听127.0.0.1。
